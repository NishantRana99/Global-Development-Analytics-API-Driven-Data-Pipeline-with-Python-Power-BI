# Global-Development-Analytics-API-Driven-Data-Pipeline-with-Python-Power-BI
API-driven global development analytics project using Python and Power BI. Data is retrieved from the World Bank API, cleaned and transformed with Pandas, and integrated into Power BI to analyze economic, health, employment, poverty, environmental, trade, and technology indicators across countries and regions.
#  world Bank Global Development Analytics

##  Project Overview

This project analyzes global economic and social development indicators using data retrieved from the **World Bank API**.

Python is used to extract, clean, transform, and prepare the data for analysis. The processed data is then integrated with **Microsoft Power BI** to create an interactive dashboard that allows users to explore economic, health, employment, poverty, environmental, trade, and technology indicators across countries and regions.

The project demonstrates an API-driven data pipeline rather than relying only on manually downloaded CSV files.

---

##  Project Objectives

The main objective of this project is to understand global development patterns and identify relationships between important economic, social, health, environmental, and technology indicators.

The analysis focuses on the following areas:

- Economic activity and GDP
- Labour market conditions
- International trade
- Poverty and inequality
- Environmental indicators
- Health indicators
- Technology and internet adoption
